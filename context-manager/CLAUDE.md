# context-manager Plugin

Intelligent project context management with semantic search support. Automatically discovers, loads, and updates project documentation from .context/ directories.

## Commands

- `/context-manager:init` - Initialize .context/ directory structure
- `/context-manager:search` - Search for relevant context documents
- `/context-manager:update` - Update context documents
- `/context-manager:status` - Show context status

## Skills

- `context-manager` - Automatically discovers and loads relevant context
